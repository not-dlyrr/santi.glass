# List

An inset grouped section: `surface` background, `radius-lg` corners, footnote header and footer in `label-secondary`.

**Consumer provides:** `ListRow` children, an optional `header` (title case, short) and `footer` (one or two plain sentences explaining the section). Pass `glass` when the list floats over imagery.

- The page behind lists is `surface-grouped`; sections are separated by `space-6`.
- Rows are separated by 0.5px `separator` hairlines inset to the text column.
